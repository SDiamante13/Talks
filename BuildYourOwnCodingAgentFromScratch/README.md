# Build Your Own Coding Agent From Scratch

## Abstract

You use AI agents every day: Claude Code, Codex, Cursor. But do you know what's actually happening under the hood? It turns out, the core of every AI agent is surprisingly simple: a while loop, a language model, and some tools.

In this live-coding session, we'll build an AI coding agent without any frameworks. We'll start from a bare frontier model call to an LLM and incrementally add capabilities. At each step, we'll hit a real limitation, understand why it exists, and solve it. You'll watch a basic chatbot evolve into a minimal coding agent with tools, conversation history, and a personalized prompt.

By the end of this session, you'll be able to:

- explain the agentic loop that powers LLM agents
- identify the core components of AI agents
- build your own simple agent and extend it with custom tools

### Prerequisites

Bring your own coding agent (Claude Code, Codex, Cursor, etc.) with an active subscription as we'll be using AI to build AI. For the agent itself, you'll need an OpenRouter.ai account (openrouter.ai). You can use free or cheap models; token usage is modest.
